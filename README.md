# To-Do-List-with-Priority-Queue
DSA Focus: Heaps/Priority Queues

Description: Build a To-Do List where each task has a priority level (e.g., 1, 2, 3). Use Python's heapq module (which implements a min-heap) or implement a simple min-heap class to ensure that the task with the highest priority (lowest number) is always the next one retrieved or viewed.
